## Disagreements kept (both names, no position)
1. qiyaman wa qu'udan wa 'ala junubihim: prayer of the sick ('Ali, Ibn 'Abbas, an-Nakha'i, Qatadah via al-Baghawi; al-Hasan via al-Qurtubi) vs constant dhikr in every state («sa'ir al-mufassirin» via al-Baghawi; al-Qurtubi's first reading; Ibn Kathir; Muyassar). At-Tabari's gloss spans both; as-Sa'di holds both. Noted: al-Baghawi lists Qatadah with the prayer reading, while at-Tabari's Qatadah quotation is about all states.
2. hadha: "this creation" (Ibn Kathir, al-Baghawi, Muyassar) vs "the commanded and forbidden creatures" (at-Tabari).
3. Reflection vs prayer: Sufis vs jurists, via Ibn al-'Arabi in al-Qurtubi (Ibn al-'Arabi's own answer reported as his).
4. as-Safa occasion: Ibn Kathir calls it mushkil; Ma'arif uses it as background.
