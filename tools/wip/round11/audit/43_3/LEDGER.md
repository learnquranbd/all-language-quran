## Watch-points
- 41:3 not cited (no fetched tafsir on 43:3 cites it); 12:2 not cited. No overlap with the 41:3 article's headings or content (41:3 used Sa'di's "most complete of languages"; not repeated).
- ja'alnahu: no fetched text discusses created vs uncreated, so the debate is not raised. Only the glosses (anzalnahu / sammaynahu wa wasafnahu / qulnahu / bayyannahu / sayyarna qira'atahu) are reported, named, unranked.
- Oath: connection attributed per tafsir (Tabari, Ma'arif, Sa'di, Qurtubi + Ibn al-Anbari, Qurtubi's "qila" on all books, Suddi, Qatada). 43:4-5 context only.

No own-voice superiority claim.
