# Indonesian conventions (set by the C1 pilot)

- Allah always (also for "God"); "Tuhan" only for a generic god / Kemenag's "Tuhanmu adalah Tuhan Yang Maha Esa" (2:163);
  shahada "tidak ada tuhan selain…" (lowercase). Pronouns for Allah capitalised: Dia, -Nya, Engkau, Dzat; His speech Aku/-Ku.
- "Lord": Rabb (Rabb kita, Rabb semesta alam, Rabb-ku/-mu/-nya; prayers "Ya Rabbku", "Ya Rabb kami").
- Nabi ﷺ / Nabi-Nya ﷺ, Rasulullah ﷺ, referred to as "beliau"; ﷺ always.
- Prophets: Indonesian form + ‘alaihissalam at first mention in a string (Musa, Ya‘qub, Yunus, Adam, Syu‘aib…);
  drop "(Jonah)" glosses; Luqman no honorific; Companions radhiyallahu ‘anhu.
- Words: ayat, surah, Al-Qur'an, Al-Fatihah, Ayat Kursi, doa, zikir / mengingat Allah, salat, tobat, takwa, tawakal,
  sabar, syukur, kufur nikmat, surga, neraka, akhirat, hari kiamat, hari pembalasan, takdir, rezeki, ibadah, amal saleh,
  ihsan, infak, muhasabah, tauhid, tasbih, wali Allah, ulul albab, ibnu sabil, hidayah, khusyuk, rida, zarah, insya Allah,
  Asmaul Husna. Divine names as Kemenag pairs (Maha Pengampun lagi Maha Penyayang; Mahaperkasa lagi Maha Pengampun…).
- Register: questions first person "aku/-ku" (never "saya"); "you" = kamu/-mu (never Anda); "we" = kita;
  lessons gentle imperatives with -lah. Quotes “ ”. Quoted ayat in Kemenag-style meaning (17:23 "uff" → "ah").
