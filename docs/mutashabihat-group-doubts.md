# Mutashabihat: groups to review

Collected 2026-10-10 from the auditors of batches M1-M9. Each line is a group whose membership the audit questioned: ayat that share only a word or a theme, a duplicate group, or real look-alikes left out. The notes for every group were still written and audited; this list is about the groups themselves (`js/mutashabihat-data.js`, MUTASHABIHAT_GROUPS), which are yours to change.
